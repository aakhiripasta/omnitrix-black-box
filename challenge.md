# The Omnitrix Black Box

The Omnitrix lost its mission log during a Plumber relay failure. Gwen recovered a file from its diagnostics, but it will not behave like an ordinary one.

Gwen believes the recovered diagnostic file contains a trail that can restore the log. Recover the mission record and determine what Vilgax learned.
